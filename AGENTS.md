# Working on this project

For every change, work in three steps, in this order:

1. **Plan.** Work out what will change and how before touching anything: read the code involved, find where it hooks in, and lay out the approach and any decisions that need the owner's input.
2. **Verify.** Check that the plan will actually work before carrying it out. Confirm that the APIs, files, settings and data it relies on exist and behave as expected. Check that it won't break anything already working, and check the real data (configs, arenas, models), not just the code.
3. **Execute.** Make the change. Then check the result (build it, run the checks or previews available, and compare against the old behaviour) and report what was and wasn't tested.
